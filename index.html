Privacy Policy

This application is a proof-of-concept for testing the integration between Meta Lead Ads and a React Native application.

Information collected

The test form may collect a person's name, email address and phone number.

How the information is used

The information is used only for demonstrating the reception and display of test leads in the Meta Lead POC application.

Data storage

This project is a development and testing proof-of-concept. Test lead information is not intended for permanent storage.

Data deletion

Test lead information can be deleted from the testing environment.

Contact

For questions about this proof-of-concept, please contact the developer through the repository associated with this project.
